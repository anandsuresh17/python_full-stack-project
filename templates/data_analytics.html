Data Analytics

Data Analytics is a career-focused course that teaches students how to collect, process, analyze, and visualize data to generate useful insights. Students learn Python, SQL, Excel, statistics, data visualization, dashboards, data analysis tools, AI tools, and practical projects.

Course Syllabus

Data Analytics Fundamentals

Understand the fundamentals of data analytics, data types, data sources, and the data analysis process.

Excel

Learn spreadsheets, formulas, functions, sorting, filtering, pivot tables, and data analysis techniques.

Python

Learn Python fundamentals and use Python for data analysis and processing.

NumPy & Pandas

Learn how to work with numerical data and analyze datasets using NumPy and Pandas.

SQL

Learn SQL queries, filtering, sorting, joins, aggregation, and working with relational databases.

Statistics

Understand basic statistical concepts used to analyze and interpret datasets.

Data Visualization

Learn how to represent data using charts, graphs, and other effective visualization techniques.

Power BI

Learn to create interactive dashboards, reports, and visualizations using Power BI.

AI Tools

Learn how modern AI tools can support data analysis, visualization, research, documentation, and workflows.

Projects

Apply your analytics skills by working with practical datasets and developing real-world style projects.
